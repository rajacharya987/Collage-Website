Place the following dependencies here:

1. GLFW — https://www.glfw.org/download.html
2. GLAD (OpenGL 4.6 Core) — https://glad.dav1d.de/

- `libs/glfw/`
- `libs/glad/` (should contain generated `include/glad`, `include/KHR`, and `src/glad.c`)
- `libs/glm/`
